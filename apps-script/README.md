# Apps Script のコード置き場

Google Apps Script のプロジェクト「Ir-rador」に貼り付けているコードの控えです。ここに置くのは**履歴を残して、前の版に戻せるようにするため**です。
GitHub から Apps Script へは自動で反映されません。直した版は、これまでどおり Apps Script のエディタに貼り替えてください。

- APIキー・Discord の Webhook・シートのIDはコードに書かず、Apps Script の「スクリプト プロパティ」に入れています（このリポジトリは公開なので、ここにも書かない）。
- 前の版に戻したいとき: GitHub でファイルを開き → History → 戻したい日の版を開いて中身をコピーし、Apps Script に貼る。

| ファイル | 役割 |
|---|---|
| IR通知.gs | TDnet の開示をAIで採点して Discord に通知（5分おき）。共通の関数（sheet_・postDiscord_ など）もここ |
| 地合い.gs | 朝8:00の地合いの通知 |
| 答え合わせ.gs | 16:10 の通知の答え合わせ |
| 週次振り返り.gs | IR通知の1週間の振り返り |
| 前引け.gs | 前引けの通知 |
| H2シグナル.gs | 決算の窓スイング（H2）の夕方のシグナル |
| 検証エンジン.gs | シート experiments の仮説を毎晩20:30に自動で検証 |
| 局面ログ.gs | 毎朝8:10に数字の層とAIの3役討論で局面ラベルを付けてシート kyokumen に1行残し、16:15に答え合わせ |
| 1分足保存.gs / 5分足書き出し.gs | 分足の保存・書き出し |
